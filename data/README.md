# AI Travel Route Planner

AI-based multi-objective travel route planning system using:

- A* Search
- Genetic Algorithm
- Simulated Annealing
- Greedy Search

## Features

- Personalized travel route optimization
- Multi-objective cost modeling
- Weather-aware transportation selection
- Multi-modal transportation support

## Project Structure

- algorithms/: search algorithms
- utils/: utility functions
- data/: datasets
- docs/: documentation
- screenshots/: demo screenshots
